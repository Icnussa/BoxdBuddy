# BoxdBuddy

A random picker for your Letterboxd watchlist, plus a yearly stats page (films watched, average rating, top genres, directors and actors).

Live site: https://icnussa.github.io/BoxdBuddy/

## Updating
Letterboxd has no public API, so the app reads Letterboxd's own data export:
open Letterboxd → Settings → Data → Export your data, then drop the ZIP into the
"Update from Letterboxd" box. One export updates the watchlist and the stats.

On this site your data is saved in your browser on each device. The claude.ai version of
BoxdBuddy also syncs between devices and can look up genre/director/cast info for new films.

## Add to your phone's home screen
Open the site in Safari (iPhone) or Chrome (Android) → Share / menu → Add to Home Screen.
